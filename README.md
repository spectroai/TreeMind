# TreeMind

支持 AI 辅助整理的桌面思维导图工具。

## 下载与安装

请前往 [Releases 下载页](https://github.com/spectroai/TreeMind/releases) 下载 `TreeMind-Setup-1.0.0-x64.exe`，双击按中文向导安装，无需安装 Python。

- 支持 Windows 10（2004及以上）/ Windows 11 x64。
- 当前发布不包含 macOS 安装包。
- 普通编辑可离线使用，AI 功能需要自行配置模型 API Key。
- 安装包未数字签名，Windows 可能提示未知发布者。

## 功能

节点编辑与左右布局、图标和样式、关联连线、AI 生成下级与整理文本、节点配图、大图查看、保存重开、撤销和导出。

安装目录附带对应项目源码、使用教程及第三方声明。
